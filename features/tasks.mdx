Pointer includes a built-in task manager that helps you stay organized. Tasks are displayed in the home view and automatically organized by due date.

## Creating tasks

Add new tasks with a simple inline form:

<Steps>
  <Step title="Type in the task input">
    Enter your task name in the "+ Add task" field at the top of the home view.
  </Step>
  <Step title="Press Enter">
    The task is created immediately with default values.
  </Step>
  <Step title="Add details (optional)">
    Click the task to open the edit dialog and add description, tags, and due date.
  </Step>
</Steps>

## Task properties

Each task includes several properties:

```typescript
userTasks: {
  tenantId: string,
  taskName: string,
  taskDescription?: string,
  category?: string,
  tags?: string[],
  completed: boolean,
  createdAt: string,
  dueBy?: string
}
```

<Tabs>
  <Tab title="Required fields">
    - **taskName**: The main task text
    - **tenantId**: User identifier
    - **completed**: Whether the task is done
    - **createdAt**: When the task was created
  </Tab>
  <Tab title="Optional fields">
    - **taskDescription**: Extended notes about the task
    - **category**: Group related tasks
    - **tags**: Multiple labels for filtering
    - **dueBy**: ISO date string for the deadline
  </Tab>
</Tabs>

  </Card>
  <Card title="This week" icon="calendar-week">
    Tasks due within the next 7 days
  </Card>
  <Card title="General" icon="list">
    All other tasks or tasks without due dates
  </Card>

### Sorting logic

```typescript
const sortedTasks = [...userTasks].sort((a, b) => {
  // Incomplete tasks first
  if (a.completed !== b.completed) {
    return a.completed ? 1 : -1;
  }
  // Then by creation date (newest first)
  return new Date(b.createdAt).getTime() - new Date(a.createdAt).getTime();
});
```

<Note>
  Incomplete tasks always appear before completed ones within each section. Within completion status, newer tasks appear first.
</Note>

## Completing tasks

Mark tasks as complete by clicking the checkbox:

```tsx
<input
  type="checkbox"
  checked={task.completed}
  onChange={(e) => onToggleComplete(task._id.toString(), e.target.checked)}
  className="h-5 w-5 rounded-full border-border text-foreground"
/>
```

Completed tasks:
- Display with strikethrough text
- Move to the bottom of their section
- Remain visible for reference

<Tip>
  You can also click directly on the task text to toggle its completion status.
</Tip>

## Task tooltips

Hover over any task to see a detailed tooltip:

```tsx
<Tooltip delayDuration={300}>
  <TooltipTrigger asChild>
    {/* Task item */}
  </TooltipTrigger>
  <TooltipContent side="bottom" align="start" className="max-w-md p-6">
    <div className="space-y-4">
      <div>
        <h4 className="font-semibold text-base">{task.taskName}</h4>
        {task.completed && (
          <span className="inline-flex items-center px-2 py-1 rounded-full 
                         text-xs font-medium bg-green-100 text-green-800">
            Completed
          </span>
        )}
      </div>
      
      {task.taskDescription && (
        <div>
          <p className="text-sm font-medium text-muted-foreground">Description</p>
          <p className="text-sm">{task.taskDescription}</p>
        </div>
      )}
      
      {/* Tags and timestamps */}
    </div>
  </TooltipContent>
</Tooltip>
```

Tooltips show:
- Task name and completion status
- Description (if provided)
- Tags with styled badges
- Creation date and time
- Due date with overdue warnings

## Querying tasks

Tasks are indexed by tenant for efficient queries:

```typescript
// Fetch all tasks for the current user
const tasks = await db
  .query("userTasks")
  .withIndex("by_tenant", (q) => q.eq("tenantId", currentTenantId))
  .collect();

// Filter completed tasks
const completedTasks = tasks.filter(task => task.completed);

// Filter by tag
const urgentTasks = tasks.filter(task => 
  task.tags?.includes("urgent")
);
```

<Tip>
  The `by_tenant` index ensures fast queries even with thousands of tasks.
</Tip>

## Date utilities

The task system uses date-fns for date handling:

```typescript
import { format, isToday, isPast, addDays } from "date-fns";

// Format for display
format(new Date(task.createdAt), "MMM d, yyyy 'at' h:mm a")
// "Dec 26, 2025 at 3:45 PM"

// Check if task is due today
isToday(new Date(task.dueBy))

// Check if task is overdue
isPast(new Date(task.dueBy)) && !isToday(new Date(task.dueBy))

// Calculate week boundary
const weekFromNow = addDays(new Date(), 7);
```
