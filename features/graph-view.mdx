The graph view provides a visual representation of your knowledge network, displaying notes, bookmarks, and thoughts as interconnected nodes. This powerful feature helps you discover relationships and patterns in your information.

## Overview

Graph view consists of several key components:

- **Graph canvas**: Interactive force-directed graph visualization
- **Timeline view**: Chronological display of your nodes
- **Tag explorer**: Filter nodes by tags
- **Quick capture**: Add new nodes without leaving the graph
- **Side panel**: View and edit node details
- **Search overlay**: Find nodes quickly with keyboard shortcuts

## Node types

The graph supports three primary node types:

  <Card title="Thought" icon="brain">

  </Card>
  <Card title="Bookmark" icon="bookmark">
    Saved links with title, URL, and optional description
  </Card>
  <Card title="Media" icon="image">

  </Card>

### Node structure

Each node contains:

```typescript
type NodeType = {
  id: string;
  type: "thought" | "bookmark" | "media";
  createdAt: string;
  tags: string[];
  // Type-specific fields
};

// Thought node
type ThoughtNode = NodeType & {
  type: "thought";
  text: string;  // Max 280 characters
};

// Bookmark node
type BookmarkNode = NodeType & {
  type: "bookmark";
  url: string;
  title: string;
  description?: string;
};

// Media node
type MediaNode = NodeType & {
  type: "media";
  caption: string;
  mediaUrl: string;
};
```

## Capturing nodes

Add new nodes to your graph using the quick capture modal:

<Steps>
  <Step title="Open the capture modal">
    Click the floating action button (+ icon) in the bottom-right corner, or use keyboard shortcuts.
  </Step>
  <Step title="Select node type">
    Choose between "Thought" or "Bookmark" tabs based on what you want to capture.
  </Step>
  <Step title="Enter content">
    - **Thought**: Type your idea (up to 280 characters)
    - **Bookmark**: Enter URL, title, and optional description
  </Step>
  <Step title="Add tags">
    Type tag names and press Enter. The modal suggests existing tags as you type.
  </Step>
  <Step title="Submit">
    Click "Add to Graph" to create the node. It will appear immediately in your graph.
  </Step>
</Steps>

## Filtering with tags

The tag explorer (desktop only) provides powerful filtering:

- **Tag list**: Shows all unique tags across your nodes
- **Click to filter**: Select tags to show only matching nodes
- **Multi-select**: Choose multiple tags to narrow your view
- **Clear filters**: Click selected tags again to remove them

```tsx
const filteredNodes = selectedTags.length > 0
  ? nodes.filter((node) =>
      selectedTags.some((tag) => node.tags.includes(tag))
    )
  : nodes;
```

<Tip>
  On mobile devices, active tag filters are shown as badges at the top of the screen. Tap a badge to remove that filter.
</Tip>

### Edges (connections)

Connections between nodes are displayed as animated edges:

```typescript
const flowEdges: Edge[] = edges.map((edge) => ({
  id: edge.id,
  source: edge.from,
  target: edge.to,
  type: "smoothstep",
  animated: true,
  style: { stroke: "#8b5cf6", strokeWidth: 2 },
  markerEnd: {
    type: MarkerType.ArrowClosed,
    color: "#8b5cf6",
  },
  label: edge.kind.replace("_", " ").toLowerCase(),
}));
```

## Side panel

Click any node to open the side panel with details:

- **Node information**: View full content and metadata
- **Edit mode**: Update node details inline
- **Related nodes**: See up to 5 related nodes
- **Delete**: Remove the node from your graph
- **Close**: Press Esc or click the close button

<Warning>
  Deleting a node also removes all edges connected to it. This action cannot be undone.
</Warning>

## Responsive design

The graph view adapts to different screen sizes:

- **Desktop**: Full tag explorer sidebar, sticky toolbar, optimized controls
- **Mobile**: Collapsible menu, touch-optimized interactions, floating tag filters
- **Tablet**: Hybrid layout with adaptive components

</Note>

## Performance considerations

<AccordionGroup>
  <Accordion title="Node positioning">
    Initial node positions use a spiral layout with randomization to prevent overlap:
    
    ```typescript
    position: {
      x: Math.cos(index * (Math.PI * 0.5)) * 300 + Math.random() * 50,
      y: Math.sin(index * (Math.PI * 0.5)) * 300 + Math.random() * 50,
    }
    ```
  </Accordion>

  <Accordion title="Related nodes limit">
    The side panel shows only 5 related nodes to keep the UI responsive:
    
    ```typescript
    relatedNodes={nodes
      .filter((n) => n.id !== selectedNode.id)
      .slice(0, 5)
    }
    ```
  </Accordion>

  <Accordion title="Animation performance">
    Framer Motion is used for smooth animations with hardware acceleration enabled by default.
  </Accordion>
