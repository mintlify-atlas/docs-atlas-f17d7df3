# Quickstart

Get up and running with Pointer quickly and start organizing your thoughts, notes, and ideas.

## Sign up for Pointer

<Steps>
  <Step title="Visit Pointer">
    Navigate to the Pointer application (web or desktop)
  </Step>
  
  <Step title="Create an account">
    Sign up using your email or social login (Google, GitHub)
    
    Pointer uses Clerk for secure authentication
  </Step>
  
  <Step title="Verify your email">
    Check your email for a verification link and click to confirm
  </Step>
  
  <Step title="Complete onboarding">
    Follow the brief onboarding flow to set up your workspace
  </Step>
</Steps>

<Tip>
  Use the same account on web and desktop to sync your notes across devices.
</Tip>

## Create your first note

<Steps>
  <Step title="Click 'New Note'">
    Press `Cmd/Ctrl + N` or click the new note button
  </Step>
  
  <Step title="Give it a name">
    Enter a descriptive name for your note
  </Step>
  
  <Step title="Start writing">
    Begin typing in the rich text editor
    
    Try these formatting options:
    - **Bold**: `Cmd/Ctrl + B`
    - *Italic*: `Cmd/Ctrl + I`
    - Headings: `Cmd/Ctrl + Alt + 1-6`
  </Step>
  
  <Step title="Watch it auto-save">
    Your note saves automatically as you type
    
    No need to manually save!
  </Step>
</Steps>

## Organize your notes

<Steps>
  <Step title="Create a folder">
    Right-click in the sidebar or use the new folder button
  </Step>
  
  <Step title="Move notes">
    Drag and drop notes into folders to organize them
  </Step>
  
  <Step title="Create nested folders">
    Build a hierarchy that makes sense for your workflow
  </Step>
</Steps>

<Note>
  Keep your folder structure simple (2-3 levels max) for easier navigation.
</Note>

## Enable collaboration

<Steps>
  <Step title="Create a collaborative note">
    Toggle collaboration when creating a new note
  </Step>
  
  <Step title="Share with others">
    Click the share button and enter collaborator emails
  </Step>
  
  <Step title="Edit together">
    Work on the same note in real-time
    
    You'll see each other's cursors and changes instantly
  </Step>
</Steps>

<Tip>
  See the [collaboration guide](/guides/collaboration) for more details on real-time editing.
</Tip>

## Getting help

<Accordion title="Can't sign in?">
  - Check that you're using the correct email
  - Try resetting your password
  - Clear browser cookies and cache
  - Contact support if issues persist
</Accordion>

<Accordion title="Notes not syncing?">
  - Check your internet connection
  - Verify you're signed into the same account
  - Look for the sync status indicator
  - Refresh the page or restart the app
</Accordion>

<Accordion title="Want to import existing notes?">
  - See the [data export guide](/guides/data-export) for import instructions
  - Pointer supports plain text and TipTap JSON formats
</Accordion>

  Need more help? Check out the full documentation or reach out to the Pointer community.
