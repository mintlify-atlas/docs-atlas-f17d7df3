## Real-time collaboration

### CRDT and sync

```json
{
  "yjs": "^13.6.27",
  "@hocuspocus/provider": "^3.4.0",
  "@tiptap/y-tiptap": "^3.0.1",
  "y-prosemirror": "^1.3.7",

}
```

**Yjs**: Conflict-free replicated data type (CRDT)
- Automatic conflict resolution
- Offline-first
- Peer-to-peer capable

**Hocuspocus**: WebSocket server for Yjs
- Connection management
- Persistence layer
- Authentication

**PartyKit**: Edge-based real-time infrastructure
- Low-latency connections
- Scalable WebSocket handling
