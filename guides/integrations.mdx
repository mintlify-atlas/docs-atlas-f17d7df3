# Integrations

Pointer includes several integrations with third-party services to enhance your productivity.

## AI integrations

Pointer integrates with AI services for intelligent features:

### Groq API

Pointer uses the Groq API for AI-powered features:

```typescript
import { groq } from "@ai-sdk/groq";
import { generateText } from "ai";
```

This powers:
- **Smart suggestions**: AI-powered writing suggestions
- **Content generation**: Help with brainstorming and writing
- **Voice transcription**: Convert voice recordings to text (desktop app)

<Steps>
  <Step title="Get API key">
    Sign up for a Groq API key at [groq.com](https://groq.com)
  </Step>
  <Step title="Configure environment">
    Add your API key to environment variables
  </Step>
  <Step title="Enable features">
    AI features will automatically become available
  </Step>
</Steps>

### AI SDK

Pointer uses Vercel's AI SDK:

```json
{
  "dependencies": {
    "@ai-sdk/groq": "^1.2.9",
    "ai": "^4.3.19"
  }
}
```

This provides:
- Streaming responses
- Type-safe API calls
- Error handling
- Retry logic

<Tip>
  The AI SDK makes it easy to switch between different AI providers if needed.
</Tip>

## Authentication

### Clerk

Pointer uses Clerk for authentication:

```typescript
import { ClerkProvider } from "@clerk/nextjs";
import { ClerkAuth } from "@convex-dev/auth/nextjs";
```

Clerk provides:
- **Multiple sign-in methods**: Email, Google, GitHub, etc.
- **Session management**: Secure token-based sessions
- **User profiles**: Customizable user information
- **Multi-factor authentication**: Optional 2FA

<Note>
  Clerk integrates seamlessly with Convex through `@convex-dev/auth`.
</Note>

## Adding custom integrations

To add your own integrations:

<Steps>
  <Step title="Install dependencies">
    ```bash
    npm install your-integration-package
    ```
  </Step>
  <Step title="Configure environment">
    Add API keys to `.env.local`
  </Step>
  <Step title="Create provider">
    Wrap your app in the integration's provider
  </Step>
  <Step title="Use in components">
    Access the integration via hooks or context
  </Step>
</Steps>

<Warning>
  Always secure API keys and tokens in environment variables, never commit them to version control.
</Warning>
