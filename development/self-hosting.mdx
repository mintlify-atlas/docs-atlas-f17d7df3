# Self-hosting

Pointer can be self-hosted, giving you full control over your data and deployment.

## Prerequisites

Before self-hosting Pointer, ensure you have:

- **Node.js**: Version 20 or later
- **npm/yarn/pnpm**: Package manager
- **Convex account**: For backend services
- **Clerk account**: For authentication
- **Domain**: (Optional) For custom domain

<Note>
  Pointer requires external services (Convex, Clerk) which have free tiers suitable for self-hosting.
</Note>

## Quick start

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/ehcaw/pointer.git
    cd pointer
    ```
  </Step>
  
  <Step title="Install dependencies">
    ```bash
    npm install
    ```
  </Step>
  
  <Step title="Configure environment">
    Copy `.env.example` to `.env.local` and fill in values
  </Step>
  
  <Step title="Set up Convex">
    ```bash
    npx convex dev
    ```
  </Step>
  
  <Step title="Run development server">
    ```bash
    npm run dev
    ```
  </Step>
</Steps>

## Environment variables

### Required variables

```bash
# Convex
NEXT_PUBLIC_CONVEX_URL=https://your-project.convex.cloud
CONVEX_DEPLOYMENT=your-deployment

# Clerk Authentication
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_...
CLERK_SECRET_KEY=sk_...

# PostHog (optional)
NEXT_PUBLIC_POSTHOG_KEY=phc_...
NEXT_PUBLIC_POSTHOG_HOST=https://app.posthog.com

# Groq API (optional, for AI features)
GROQ_API_KEY=gsk_...
```

<Warning>
  Never commit `.env.local` to version control. Keep your secrets secure.
</Warning>

## Setting up Convex

<Steps>
  <Step title="Create Convex project">
    Visit [convex.dev](https://convex.dev) and create a new project
  </Step>
  
  <Step title="Install Convex CLI">
    ```bash
    npm install -g convex
    ```
  </Step>
  
  <Step title="Initialize Convex">
    ```bash
    npx convex dev
    ```
    
    Follow the prompts to link your project
  </Step>
  
  <Step title="Deploy functions">
    Convex automatically deploys your functions from the `convex/` directory
  </Step>
</Steps>

### Convex schema

Pointer's schema is defined in `convex/schema.ts`:

```typescript
import { defineSchema, defineTable } from "convex/server";

export default defineSchema({
  notes: defineTable({...}),
  whiteboards: defineTable({...}),
  userTasks: defineTable({...}),
  // ... more tables
});
```

<Tip>
  Convex automatically handles database migrations when you update the schema.
</Tip>

## Setting up Clerk

<Steps>
  <Step title="Create Clerk application">
    Visit [clerk.com](https://clerk.com) and create a new application
  </Step>
  
  <Step title="Configure authentication methods">
    Enable desired sign-in methods (email, Google, GitHub, etc.)
  </Step>
  
  <Step title="Get API keys">
    Copy the publishable and secret keys to your `.env.local`
  </Step>
  
  <Step title="Configure redirect URLs">
    Set allowed redirect URLs in Clerk dashboard:
    - `http://localhost:3000` (development)
    - `https://yourdomain.com` (production)
  </Step>
</Steps>

### Clerk + Convex integration

Pointer uses `@convex-dev/auth` to integrate Clerk with Convex:

```typescript
// convex/auth.config.ts
import { convexAuth } from "@convex-dev/auth/server";

export const { auth, signIn, signOut } = convexAuth({
  providers: [],
});
```

### Docker

Create a `Dockerfile`:

```dockerfile
FROM node:20-alpine AS builder

WORKDIR /app
COPY package*.json ./
RUN npm ci

COPY . .
RUN npm run build

FROM node:20-alpine AS runner
WORKDIR /app

ENV NODE_ENV production

COPY --from=builder /app/public ./public
COPY --from=builder /app/.next/standalone ./
COPY --from=builder /app/.next/static ./.next/static

EXPOSE 3000
CMD ["node", "server.js"]
```

Build and run:

```bash
docker build -t pointer .
docker run -p 3000:3000 --env-file .env.local pointer
```

## Setting up collaboration server

For real-time collaboration, you need a Hocuspocus server:

### Option 1: Hocuspocus Cloud

Use the hosted Hocuspocus service (easiest)

### Option 2: Self-hosted Hocuspocus

```javascript
// server.js
import { Server } from "@hocuspocus/server";

const server = Server.configure({
  port: 1234,
  
  async onAuthenticate({ token }) {
    // Verify user token
  },
  
  async onStoreDocument({ documentName, document }) {
    // Save to Convex
  },
});

server.listen();
```

Run the server:

```bash
node server.js
```

<Note>
  Point your Pointer app to the Hocuspocus server URL in environment variables.
</Note>

### Option 3: PartyKit

Deploy to PartyKit for edge-based collaboration:

```bash
cd partykit
npx partykit deploy
```

## Security

### HTTPS

Always use HTTPS in production:

- Let's Encrypt (free)
- Cloudflare (free tier available)
- Your hosting provider's SSL

### Environment security

```bash
# Use a secrets manager
AWS Secrets Manager
HashiCorp Vault
Vercel Environment Variables
```

### Content Security Policy

Add CSP headers in `next.config.ts`:

```typescript
const nextConfig = {
  async headers() {
    return [
      {
        source: '/(.*)',
        headers: [
          {
            key: 'Content-Security-Policy',
            value: "default-src 'self';"
          }
        ]
      }
    ]
  }
}
```

## Troubleshooting

### Build failures

```bash
# Clear cache
rm -rf .next
npm run build

# Check Node version
node --version  # Should be 20+
```

### Convex connection issues

1. Verify `NEXT_PUBLIC_CONVEX_URL` is correct
2. Check Convex dashboard for service status
3. Ensure functions are deployed: `npx convex deploy`

### Authentication problems

1. Verify Clerk keys are correct
2. Check redirect URLs in Clerk dashboard
3. Clear browser cookies and try again

<Warning>
  Always test thoroughly in a staging environment before deploying to production.
</Warning>
