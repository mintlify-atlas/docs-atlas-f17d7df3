# Welcome to Pointer

Pointer is a modern note-taking and knowledge management platform designed to help you do your best thinking. With powerful features like real-time collaboration, knowledge graphs, and interactive whiteboards, Pointer provides everything you need to capture, organize, and connect your ideas.

## Built with modern technology

Pointer is built on a robust technology stack:

- **Frontend**: Next.js 16 with React 19 and TypeScript
- **Backend**: Convex for real-time data synchronization
- **Editor**: TipTap for rich text editing
- **Collaboration**: Yjs and Hocuspocus for real-time collaboration
- **Desktop**: Tauri for native desktop apps
- **Authentication**: Clerk for secure user management
- **UI**: Radix UI components with Tailwind CSS
